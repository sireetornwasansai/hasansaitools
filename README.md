# HA Round — แผน HA / HAIT / Hospital Round (รพ.สันทราย จ.เชียงใหม่)

Frontend: GitHub → Vercel (static) · Proxy: `/api/gas` · Backend: Google Apps Script + Google Sheets

## โครงสร้าง
- `public/` หน้าเว็บ (index.html, css/app.css, js/app.js, data/plan.json, manifest.webmanifest, icons/)
- `api/gas.js` proxy บน Vercel (ซ่อน URL และ secret ของ GAS)
- `gas/` โค้ด Apps Script (Code.gs, appsscript.json)

- **รายงานการประชุมรูปแบบราชการ (ใหม่)**: เพิ่มช่อง เวลาเลิกประชุม / ผู้จดรายงาน / ผู้ตรวจรายงาน · เอกสารพิมพ์/Word แสดง ผู้มา-ไม่มาประชุมแบบเรียงเลข, เริ่ม-เลิกประชุมเวลา, ระเบียบวาระที่ N, มติเป็นตาราง (ผู้รับผิดชอบ/กำหนด/สถานะ), ชื่อผู้ลงนาม · ข้อมูลเก่าใช้ได้ต่อ (ช่องใหม่ว่างได้) ไม่ต้องแก้ GAS แค่ Redeploy Vercel
- แท็บ "ประชุม": บันทึกรายงานการประชุม QMR (วันที่ ผู้เข้าร่วม วาระ สรุป มติ) · มติแต่ละข้อสร้างเป็นประเด็นติดตามอัตโนมัติ (หน่วยงาน คณะกรรมการ QMR) แล้วแสดงสถานะ ปิดแล้ว/เกินกำหนด ในรายงาน · ยกมติค้างเข้าวาระครั้งต่อไป · คัดลอกสรุปไปวางใน LINE · พิมพ์ PDF · ส่งออก CSV (เก็บในช่อง plus คีย์ mtg:ID ไม่ต้องแก้ GAS)
- แท็บ "มาตรฐาน": ประเมินตนเองรายมาตรฐาน HA ฉบับที่ 6 (58 รายการ: ตอน I-II ระดับข้อ ก/ข/ค, ตอน III-IV ระดับบท; ข้อมูลอยู่ใน plan.json คีย์ ha6) (คะแนน 1-5) + นับประเด็นที่อ้างมาตรฐานนั้น + พิมพ์/ส่งออก CSV (เก็บในช่อง plus ด้วยคีย์ std:ID ไม่ต้องแก้ GAS)

- **บันทึกข้อความ (ใหม่)**: ในแท็บ "ประชุม" กด "+ บันทึกข้อความ" หรือปุ่ม "บันทึกข้อความ" ในการ์ดการประชุม · 4 ประเภท (เชิญประชุม / ส่งรายงานและแจ้งมติ / ติดตามมติค้าง-เกินกำหนด / ทั่วไป-ขออนุมัติ) ร่างเนื้อความให้จากข้อมูลการประชุมและมติ แก้ได้ก่อนออกเอกสาร
  - โหมดทีม: สร้าง **Google Docs + Word (.docx) + PDF** ใน Drive หมวด "คำสั่ง/ประกาศ/หนังสือราชการ" · ออกเลขที่อัตโนมัติ (001/2569 เริ่มใหม่ทุกปี พ.ศ. ไม่เสียเลขถ้าสร้างล้มเหลว) · ไฟล์ขึ้นแท็บ "เอกสาร" ด้วย · มีประวัติ แก้ไข/สร้างใหม่ (เลขที่เดิม) และลบ · ข้อมูลทุกช่องถูกตรวจ/ล้างอักขระที่เซิร์ฟเวอร์อีกครั้ง
  - โหมดเครื่องนี้: ดูตัวอย่าง พิมพ์/บันทึก PDF และดาวน์โหลด Word (.doc) ได้ทันที (ไม่ต้องมี Drive)
  - รายงานการประชุมดาวน์โหลดเป็น Word (.doc) ได้จากปุ่ม "Word (.doc)" ในการ์ดการประชุม
  - ตั้งค่าเพิ่มใน Script properties (ไม่บังคับ): `MEMO_DOCNO_PREFIX` (เช่น `ชม 0033.301/`) · `MEMO_TEMPLATE_ID` (Google Docs ต้นแบบที่ใช้ `{{DOC_NO}} {{DOC_DATE}} {{FROM}} {{TO}} {{SUBJECT}} {{ATTACH}} {{CONTENT}} {{NAME}} {{POSITION}} {{CONTACT}}` ไม่ใส่ = ใช้รูปแบบมาตรฐานของระบบ) · `MEMO_LOGO_ID` (ไอดีไฟล์ภาพครุฑใน Drive) · `MEMO_FONT` (ค่าเริ่มต้น Sarabun)
  - **หลังอัปเดต `Code.gs`**: รันฟังก์ชันใดก็ได้ใน Apps Script หนึ่งครั้งเพื่อกดอนุญาตสิทธิ์ใหม่ (Docs + เชื่อมต่อภายนอก) แล้ว Deploy เวอร์ชันใหม่บน deployment เดิม และ Redeploy Vercel (ต้องใช้ `api/gas.js` และ `vercel.json` ตัวใหม่)

- **ใช้ได้ทุกอุปกรณ์ (UX v3)**: มือถือ = เมนูล่างมีไอคอน, หน้าต่างเลื่อนขึ้นจากล่างพร้อมปุ่มบันทึกติดขอบล่าง, รองรับรอยบากจอ/แนวนอน · แท็บเล็ต = หน้าต่างกลางจอ, การ์ดสองคอลัมน์ · เดสก์ท็อป (กว้าง ≥1024px) = แถบเมนูด้านข้าง, ปฏิทินซ้าย-กิจกรรมขวา, การ์ดหลายคอลัมน์ · ปุ่มสัมผัส ≥44px, ฟอร์มไม่ซูมเองบน iOS, โหมดมืด/คอนทราสต์สูง/ลดการเคลื่อนไหว · ตัวอย่างบันทึกข้อความย่อให้พอดีทุกขนาดจอ · ติดตั้งเป็นแอปบนหน้าจอหลักได้ (PWA: `manifest.webmanifest`, `icons/`) · ฟอนต์ IBM Plex Sans Thai / Sarabun โหลดแบบไม่บล็อกหน้า
- ความเร็ว/การตอบสนอง: หน้าโหลดแผนพร้อมกับสคริปต์ (preload) มีหน้า Loading และปุ่มลองใหม่ · แถบความคืบหน้าด้านบนทุกครั้งที่คุยกับเซิร์ฟเวอร์ · ปุ่มที่บันทึกแสดงวงหมุนและกดซ้ำไม่ได้ระหว่างรอ · timeout 25 วินาที (ไฟล์ 90 วินาที) ไม่ให้ค้าง · แสดง skeleton ระหว่างรอข้อมูลทีมครั้งแรก · รองรับ prefers-reduced-motion

## ติดตั้ง (ทำครั้งเดียว)
1. สร้าง Google Sheet ใหม่ → Extensions → Apps Script → วาง `gas/Code.gs` (และ appsscript.json ถ้าเปิด manifest)
2. Project Settings → Script properties เพิ่ม `TEAM_KEY` (รหัสผ่านทีม) และ `GAS_SECRET` (สตริงสุ่มยาว ๆ)
3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → คัดลอกลิงก์ `/exec`
4. Push โปรเจกต์ขึ้น GitHub → Import เข้า Vercel
5. Vercel → Settings → Environment Variables: `GAS_URL` = ลิงก์ `/exec`, `GAS_SECRET` = ค่าเดียวกับในข้อ 2 → Redeploy
6. (ไม่บังคับ) สิทธิ์ดูอย่างเดียว: เพิ่ม Script property `VIEW_KEY` — คนที่ใช้รหัสนี้จะเห็นข้อมูลแต่แก้ไม่ได้ (ให้ผู้บริหารใช้)
7. (ไม่บังคับ) แจ้งเตือนเกินกำหนด: เพิ่ม `NOTIFY_EMAILS` (คั่นด้วย ,) แล้วรัน `setupDailyDigest` — ส่งอีเมลทุกวัน 08:00
8. (ไม่บังคับ) ย้ายข้อมูลเก่า: เปลี่ยนชื่อชีตเก่าเป็น `Issues_old` แล้วรัน `migrateFromLegacy`
9. (ไม่บังคับ) ไฟล์แนบบน Google Drive: เพิ่ม `FOLDER_ID` (ไอดีโฟลเดอร์ Drive ที่ต้องการ ถ้าไม่ใส่ระบบสร้าง `HA-Round-Files` ให้) และ `SHARE_MODE` = `private` (ค่าเริ่มต้น: แชร์โฟลเดอร์ให้ทีมเอง) | `domain` | `link` — ครั้งแรกที่ Deploy ต้องกดอนุญาตสิทธิ์ Drive
10. (ไม่บังคับ) รันฟังก์ชัน `setupWeeklyBackup` ใน Apps Script เพื่อสำรองชีตทุกสัปดาห์

## ไฟล์แนบ (แท็บ "เอกสาร" และปุ่ม "แนบไฟล์" ในการ์ดประเด็น — โหมดทีมเท่านั้น)
- ไฟล์เก็บใน Google Drive แยกโฟลเดอร์ตามหมวด · รายการ+URL เก็บในชีต `Files` · คอลัมน์ `files` ของชีต `Issues` แสดงชื่อ+ลิงก์ไฟล์ของแต่ละประเด็น
- ทำได้: อัปโหลดหลายไฟล์ (ไม่เกิน 20 MB/ไฟล์, ส่งเป็นชิ้น 2.25 MB ผ่าน proxy) · ค้นหา/กรองหมวด · เปิดใน Drive · คัดลอกลิงก์ · แก้ชื่อ/หมวด/อ้างอิง/คำอธิบาย/ประเด็นที่ผูก (เปลี่ยนชื่อและย้ายโฟลเดอร์ใน Drive ให้) · ลบ (ไฟล์เข้าถังขยะ Drive กู้ได้ 30 วัน) · ส่งออก CSV มีคอลัมน์ไฟล์แนบ
- ไม่รับไฟล์โปรแกรม/สคริปต์ (exe, bat, js, sh ฯลฯ) · แอป `private` ต้องแชร์โฟลเดอร์ใน Drive ให้ผู้ใช้ทุกคนเอง ไม่งั้นเปิดลิงก์ไม่ได้
- หลังอัปเดต `Code.gs` และ `api/gas.js` ต้อง Deploy GAS เวอร์ชันใหม่ และ Redeploy Vercel

## อัปเดต GAS ภายหลัง
Deploy → Manage deployments → Edit → New version บน deployment เดิม (ห้ามสร้างใหม่ ลิงก์จะเปลี่ยน)

## แก้แผน
แก้ `public/data/plan.json` แล้ว commit — Vercel deploy ให้อัตโนมัติ
